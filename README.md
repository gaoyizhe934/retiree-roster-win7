# 退休人员名册打印小程序

面向 Windows 7 RTM 的离线本地桌面程序，用于将退休人员 Excel 资料导入统一基础库，按业务条件筛选人员，并生成可直接打印的 Excel 名单。

项目仍处于基础设计阶段。目前公开的 C++ 代码是跨模块共用的数据类型契约，尚未提供可运行程序。

## 建设目标

- 在本地维护一人一档的退休人员基础库。
- 通过出生日期、入党日期和维护状态自动支持年龄、党龄与组合筛选。
- 生成发放、重阳节祝寿、党员和党龄纪念等名单。
- 导出大字号、可分页、可签字、可复用的 Excel 打印表。
- 保留离世人员历史、导入批次、数据变更记录以及备份恢复能力。

## 首期能力

| 模块 | 计划能力 |
| --- | --- |
| Excel 导入 | 选择工作表、识别表头、字段映射、预览、校验、重复候选识别和确认入库。 |
| 人员档案 | 搜索、新增、修改、标签维护、在世转去世和历史查询。 |
| 筛选与名单 | 周岁、当年年龄、党龄、常用场景、组合条件、拼音排序和打印序号。 |
| 打印输出 | 可配置字段、列顺序、字号、纸张、分页、重复表头和签字栏。 |
| 本地管理 | SQLite 数据库、导入批次、操作记录、备份与恢复。 |

## 表头导入规则

程序采用两层导入策略：

1. 以 `reference/员工信息表11111.xlsx` 的第三行作为标准转换模板。表头名称和顺序完全一致时，程序直接进入导入预览。
2. 表头存在缺失、重复、名称差异或顺序差异时，程序进入映射确认流程。系统先给出预设同义字段映射，无法可靠匹配的字段必须由用户确认，不能猜测填入。

导入前不会写入正式库。导入预览会列出已映射字段、待确认字段、未映射源列、目标字段缺口和数据校验问题。

## 技术方向

- 运行环境：Windows 7 RTM，优先提供 32 位免安装版本。
- 语言与界面：C++14、Win32 API 和 Common Controls。
- 本地数据：静态集成 SQLite。
- Excel：静态集成 xlsx 读写组件，不依赖目标机器安装 Microsoft Excel。
- 编码：Unicode 与 UTF-8 边界转换，确保中文姓名、地址和文件名正常处理。

## 代码结构

```text
include/retiree_roster/schema_types.hpp  人员、导入、筛选、打印和 API 的统一类型契约
docs/                                   项目需求与开发规划
reference/                              无个人数据的表头模板与任务清单
```

`schema_types.hpp` 是当前唯一的公共数据契约。任何模块使用人员字段、导入绑定、筛选条件、打印列或 API 请求时，都应以其中的 `FieldId`、`PersonRecord` 和相关 DTO 为准，避免自由字段名在界面、数据库、xlsx 适配器和打印模块之间漂移。

## 开发计划

项目按七个阶段推进：需求与样表盘点、技术与数据结构设计、Excel 导入与人员维护、筛选计算与名单生成、打印模板与输出、集成测试与迁移演练、试运行与交付。具体任务见 `reference/七阶段开发任务清单.xlsx`，详细说明见 `docs/`。
