# 标识符与编号口径

状态：待审契约，未冻结。需求 R05 确认“固定编号与当次序号分离”，未说明工号是否就是固定编号。

| 名称 | 契约 | 语义 |
| --- | --- | --- |
| 内部人员 ID | PersonId／person_id | 系统内部永久 ID、不复用；关联数据库／标签，R04 排序最后一键 |
| 源工号 | EmployeeNo／employee_no | 源表文本，可能空或重复；不能单独作为自动去重主键 |
| 固定人员编号 | PersonCode／person_code | 候选用户可见永久业务编号；系统分配、创建后只读、不复用 |
| 当次打印序号 | DerivedColumnId::PrintSerialNumber | 每次生成后在快照内从 1 连续分配，排序变化后重新生成 |

本轮用 PersonCode 明确表达固定编号，不再把 UI 固定编号指向 PersonId。具体格式／生成方式以及甲方是否确认 EmployeeNo 等同固定编号仍待确认。若确认等同，则以批准的局部变更撤销 PersonCode，不保留两个可写的固定编号来源。

PersonCode 尚未有运行实现，此处只解决字段语义与评审入口。导入不得为系统 ID 或固定编号开放自由映射；历史迁移方案需另行验证。
