# 本地操作员说明

OperatorContext 表示本机操作日志的归属，不代表登录、身份认证或权限控制。首期不实现权限服务器。

首次启动可填写维护人员显示名，或使用固定本机维护员标识。`operator_id` 采用稳定的本机非空标识，`display_name` 用于显示；修改显示名不修改已归档的操作记录。

`UserId` 在本轮草案中保留为日志标识的类型名。confirmed_by、changed_by、requested_by、executed_by、updated_by／last_modified_by 均由本地 OperatorContext 填写。它们不能作为授权判定，也不证明某位自然人实际执行。

未来管理员手册须包含配置／更换显示名的步骤及以上含义。本轮没有创建可运行的首次启动界面。
