## R01–R05 对照

| 条款 | FilterSpec／结果形态 | 验收口径 |
| --- | --- | --- |
| R01 周岁／当年年龄 | as_of_date（完整日期）、target_year、AgeBasis、age | 周岁需完整生日，当年年龄只需出生年；测试传固定日期 |
| R02 重阳节 | scenario=Chongyang、LivingOnly、CalendarYearAge、age={70,75,80,85} 或 >=90 | 89 不入、90/91 入、去世 90 默认不入 |
| R03 党龄 50 | scenario=Party50、require_party_member、party_seniority={50} | 目标年减入党年；非党员／缺年／非 50 排除 |
| R04 稳定排序 | RosterResult.rows | 拼音键、姓名、PersonId 依序比较；所有输出保留该顺序 |
| R05 编号 | PersonCode 与 PrintSerialNumber | 固定编号只读，临时序号每次从 1 连续生成 |

服务统一将场景展开成有效条件，并将展开后的 FilterSpec 放进快照。Chongyang 按 R02 默认在世；Party50 按 R03 要求党员且党龄为 50，不额外限制在世／去世，服从调用方显式传入的 LifeStatusFilter。Party50 的 UI 默认状态仍待业务确认，不强迫去世党员改用 Custom。

Custom 使用显式 LivingOnly／DeceasedOnly／All。FilterSpec 初始状态为 Unspecified，服务不得把它静默当作在世；Chongyang 可按已明确的 R02 展开为 LivingOnly，Custom／Party50 需明确选择状态后生成。场景字段与其固定规则相冲突时返回 ValidationFailed，不能让 UI 与服务采用不同优先级。target_year 必须有效，as_of_date 不得隐式读取全局时钟；UI 可以传入当天完整日期。

YearCountCondition 的语义是：关闭时不约束，开启时 accepted_values 中任一个值 **或** inclusive minimum 下限满足即匹配；开启但既无集合也无下限为非法。All／Any 分别组合 field conditions 和 tag conditions；状态、年龄、党龄与这两组之间为 AND。空字段／标签集合表示不约束，不用空 Any 排空结果。日期不足的派生值为 -1，仅表示不可计算，不能参与年龄／党龄比较。

具体枚举（性别、类别、级别、党员）、条件值域、拼音规范化／中文排序实现由 A/R 确认；不从字符串“看起来像党员”推断。规范化方法和规则引擎留给 D4，预期样例见 tests/contract/chongyang_cases.csv。

## 模板与同一名单

PrintTemplate 的 columns 数组顺序即列序，visible 控制显示。source 分 PersonField、DerivedField、BlankSignature、StaticText，只读取相应成员；非活动成员不解释。DerivedColumnId 包含打印序号、周岁、当年年龄和党龄。签字列显式放在 columns，不保留第二个 add_signature_column 开关；备注用普通 PersonField。

纸张显式 A4，方向显式 Portrait／Landscape。列宽、四边距、行高统一用 0.1mm 整数，字号用 pt；标题／表头字号、每页人数、重复表头、页码策略也在模板内。rows_per_page=0 表示由版式服务计算容量，正数必须经过可容纳性验证，不能压缩／截断行。

版式服务按 A4 的 2100×2970（横向反转）、页边距、标题／表头／页脚及打印机硬边距验证。GDI 与 xlsx 适配器各自转换同一物理语义；xlsx 字符宽度转换仍需字体度量、打开核对及实物证据，整数单位不是兼容性证明。非法版式返回 InvalidTemplate。

三条输出路径都引用同一 snapshot_id；PrintModel 消费不可变快照与模板，不重新查询／筛选数据库。具体旧快照失效行为见 [ADR-0003](../decisions/ADR-0003-名单快照与输出一致性.md)。
