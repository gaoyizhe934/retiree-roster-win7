# ADR-0001 仓库基线权威顺序

状态：Proposed（待 A/B/C/R 复核）；批准人／日期／证据：未提供。

问题：README、提前定义的 Schema 和未合并设计稿被混用为业务依据，开发者无法判断冲突应遵从谁。

提案：采用[七层权威顺序](../baseline/00_基线与权威来源.md)。Owner Decision／ADR 只有批准后且仅对列明条款有覆盖效力；当前公共契约为 Draft，README 为入口，任务台账不反向改需求。Gate 质量结论仅由正式承担评审角色的非作者 R 写入 Gate Status；创建者的 Git 授权另行记录，作者不得通过身份切换自签。

影响：A/B/C 在共同契约中提出变更，附业务条款及验证；不能各自私下定义新 DTO。R 以冲突条款及批准证据判断基线，不按文件时间判断。

验收：README 不再定义第三行永久直入规则，所有入口能到达同一基线及 Gate 状态。批准后才将本 ADR 状态改为 Accepted。
