# ADR-0002 日期精度模型

状态：Proposed；批准人／日期／证据：未提供。依据：源表出生年月／工作时间／退休时间及需求 R01、R03。

提案：使用 DateValue，precision 为 Unknown、Year、YearMonth、FullDate。缺失组件为 0，绝不补当月 1 日或 1900-01-01。Unknown 必须全部为 0；已知年为 1–9999，月份与完整日期按公历校验（含世纪闰年）。导出按原精度显示，UI 明示日期不完整。

周岁须 FullDate 和完整 as_of_date；当年年龄及“目标年减入党年”的党龄只要求已知有效年。精度不足的值不参与对应精确规则，不能按 0 岁或猜测日期入选。党龄 50 年同时要求已确认党员代码，代码映射留在 Profile。

LocalDate 仅保留 DateValue 的过渡别名，三元组旧调用必须显式补 precision；不提供推断精度的兼容构造。FieldChange 的日期字段使用 date_value，清除优先，源文本解析由导入适配器完成。

验证：tests/contract/date_value_test.cpp 通过公共日期接口检查四种精度、非法日期和伪造日值。生日、跨年、闰日年龄计算在 D4 规则引擎验证，日期结构测试不代替规则验收。
