# ADR-0004 标签与关怀状态模型

状态：Proposed；批准人／日期／证据：未提供。依据：需求 Tag 对象和“人工维护困难、长期患病、慰问”边界。

提案：TagRecord 是人工关怀状态唯一持久化来源，PersonRecord 不再含 CareFlags 或对应布尔字段，PersonFieldId 不含 TagCodes。标签更新走独立 UpdateTagRequest，记录操作员及时间。常年状态 applicable_year=0；当年慰问必须绑定具体年，不能跨年继承“今年已慰问”。

高龄结果按当前筛选方案的年龄规则派生，不持久化 IsHighAgeMarked，不借此自动推断困难、疾病或慰问。若甲方需要独立人工标记，必须批准不同名称与语义，不能写回派生年龄状态。

TagCondition 指定代码、值及适用年，集合以 All 或 Any 组合；Tag 表唯一键建议 (person_id, tag_code, applicable_year)，成员值编码待 A/R 确认。筛选和人员 UI 都使用同一标签来源，输出使用快照内标签副本。

影响：D1B 原 29 字段表、TagCodes 和四个 CareFlags 项需在稳定化基线合入后重做，旧字段不自动映射到新 Person。当前没有已发布数据库，D2/D3 落库仍需明确迁移与唯一约束。
