# OD-0001 分支命名规则

状态：Accepted，仅限分支命名。决定人：仓库创建者；记录日期：2026-10-01。批准依据是创建者在本任务直接提供的 Personal global instructions，不是修复清单或代理推断。

## 原始指令摘录

> 今后创建的分支名必须仅使用 ASCII 字符，禁止中文及其他非 ASCII 字符；适用于所有仓库和新任务。
>
> 分支使用对应类型前缀，格式为 `类型/简短英文主题`，例如 `feat/hybrid-search-fusion`、`docs/d1b-workflow-template-design`；主题使用小写英文、数字和连字符。
>
> 不得沿用旧文档中的中文分支示例；遇到既有规则要求中文分支时，按本条最新用户偏好使用 ASCII 分支名。
>
> 此要求只改变分支命名；Commit 信息仍使用上述中文摘要规范。

## 覆盖范围

该明确指令只覆盖旧规划与协作规则中的中文主题分支要求。新分支继续使用 `feat`／`fix`／`docs`／`test`／`refactor`／`chore` 前缀及英文主题，完整规则见[协作命名规范](../../GitHub协作命名规范.md)。现有他人分支不擅自重命名，不改写历史。

#2 返工清单 P0-01 所称“无授权 ASCII 规则”与以上原始指令不符，因此本轮保留 ASCII，补齐决定来源。若创建者今后明确撤销此偏好，再记录新的决定；普通附件中的相反建议不自动撤销用户直接指令。

本决定不批准其他 ADR、公共契约、业务参数或 Gate；Gate 质量签认仍由非作者 R 负责。
