# OD-0003 D2 正式构建工具集与镜像口径

状态：Accepted，仅限 D2 正式构建的工具集选择方式、XMake 镜像口径与 Gate 0 前的 D2 预开发例外。决定人：仓库创建者；记录日期：2026-10-06。依据创建者在本任务的直接指示（“继续工作，无需给出gate0”）以及对下列三项收口条款的明确接受。

## 背景

[PR #10](https://github.com/gaoyizhe934/retiree-roster-win7/pull/10) 的 Formal Review 提出四点，其中三项需要受控收口：

1. `CMakeLists.txt` 在项目代码中 `FORCE` 写 `CMAKE_GENERATOR_TOOLSET` 属于未定义行为，且记录的正式命令未含 `-T`，无法证明从全新构建目录得到同一工具集；
2. `docs/status/GATE_STATUS.md` 仍记 Gate 0 未通过、Gate 1 未进入；
3. `docs/dependencies/THIRD_PARTY.md` 仍写仓库没有第三方源码，与本 PR 已纳入的 SQLite 3.45.3 不一致；
4. 任务台账写 CMake/XMake “均锁定 … MSVC2017 v141_xp”，与 XMake 仅使用 v141 编译器的实现口径冲突。

## 决定条款

| 条款 | 决定 |
| --- | --- |
| 正式工具集选择 | 正式 CMake 配置命令使用 `-T v141_xp`。`CMakeLists.txt` 不写 `CMAKE_GENERATOR_TOOLSET`；仅在 `project()` 后断言 `CMAKE_VS_PLATFORM_TOOLSET` 等于 `v141_xp`，否则配置报错 |
| 受控命令修订 | 规划中固定的 CMake 配置命令补 `-T v141_xp`，其余参数（`-G "Visual Studio 15 2017"`、`-A Win32`、`-DAPP_STATIC_RUNTIME=ON`、`-DAPP_ENABLE_TESTS=ON`）不变。该修订是本决定对基线命令缺口的登记与解决 |
| XMake 镜像口径 | XMake 仅为开发机快速构建与配置一致性复核：使用 v141 编译器（`--vs=2017`），镜像 Win32/C++14//MT/Unicode/`WINVER=_WIN32_WINNT=0x0601` 与同一依赖源码；不启用 v141_xp。任务台账“均锁定 … MSVC2017 v141_xp”据此解释为：v141_xp 是正式（CMake）候选包的锁定要求，XMake 镜像同一 v141 编译器与 Win7 宏/运行库；正式候选包只由 CMake install 生成 |
| D2 预开发例外 | 创建者指示在 Gate 0 正式签认前继续 D2-C 的返工与提交。本例外仅为明确的受控流程例外，不改变 Gate 1 结论由非作者 R 给出，也不构成 Gate 0 PASS |

## 边界

- 本决定不改业务契约、目标 OS、依赖版本或发行架构。
- D2-C 的配置、构建、测试、候选包与 VM 证据必须在受控命令下从全新构建目录重跑后再交 R 复核。
- 历史记录中的旧命令与旧口径保留原文；当前要求由本决定替代。
- 第三方依赖台账的同步属于同一返工范围：已纳入的 SQLite 记录实际状态，未消费依赖仍记未纳入。
